Aula 14 - Atividade Prática

Laboratório de Testes com PHPUnit: Chão de Fábrica e OEE

1. Objetivos da Atividade

Esta atividade prática visa consolidar os conceitos de Testes Unitários e Testes de Integração utilizando o framework PHPUnit. Você atuará como um desenvolvedor encarregado de identificar e expor falhas ocultas no motor de regras de um painel de monitoramento de produção (Dashboard OEE) voltado para extrusoras e injetoras.

Ao final deste laboratório, você deverá ser capaz de:

  • Configurar e arquitetar de forma autônoma o ambiente do PHPUnit.
  • Escrever asserções unitárias para validar tratamento de exceções e limites de valores (Boundary Testing) em indicadores industriais.
  • Desenvolver testes de integração que validam a persistência correta de múltiplos registros contínuos.

Atenção: Todo o ecossistema de comandos deste documento foi desenhado para execução no terminal do Windows (PowerShell ou CMD). Certifique-se de utilizar as barras invertidas (\) corretas ao referenciar executáveis locais.

2. Preparação do Ambiente

Siga os passos abaixo para estruturar o projeto:

  1. Abra o terminal na pasta de sua preferência e crie o diretório do projeto: 
    mkdir painel-oee-tests
cd painel-oee-tests
  2. Inicialize o Composer e adicione o PHPUnit: 
    composer require --dev phpunit/phpunit
  3. Crie a estrutura de diretórios: 
    mkdir src
mkdir tests
  4. Configure o autoloading padrão PSR-4 no composer.json mapeando App\\ para src/, e execute composer dump-autoload.
  5. Crie o arquivo phpunit.xml na raiz para habilitar cores e apontar para a pasta tests.

3. O Código Fonte sob Suspeita

Crie o arquivo MonitorProducao.php dentro de src/ e cole o código abaixo. Esta classe possui três bugs críticos relacionados à lógica de telemetria.

<?php

namespace App;

class MonitorProducao
{
    private string $caminhoLog = 'telemetria_maquinas.jsonl';

    public function calcularDisponibilidade(int $tempoPlanejado, int $tempoParada): float
    {
        // Regra de Negócio: A disponibilidade é a razão percentual entre o tempo produtivo e o tempo planejado.
        // O tempo produtivo é o tempo planejado subtraído do tempo de parada.
        $tempoProdutivo = $tempoPlanejado - $tempoParada;
        
        return ($tempoProdutivo / $tempoPlanejado) * 100;
    }

    public function verificarTemperatura(float $temperaturaAtual): string
    {
        // Regra de Negócio: Por motivos de segurança, extrusoras operando a partir de 180°C
        // devem acionar o status 'ALERTA_CRITICO'. Caso contrário, 'OPERACAO_NORMAL'.
        if ($temperaturaAtual > 180.0) {
            return 'ALERTA_CRITICO';
        }

        return 'OPERACAO_NORMAL';
    }

    public function registrarLeitura(string $codigoMaquina, array $dados): bool
    {
        $leitura = [
            'maquina' => $codigoMaquina,
            'dados' => $dados,
            'timestamp' => date('Y-m-d H:i:s')
        ];

        $json = json_encode($leitura) . PHP_EOL;

        // Persiste a leitura em um arquivo de log para auditoria futura
        return file_put_contents($this->caminhoLog, $json) !== false;
    }

    public function lerHistoricoTotal(): array
    {
        if (!file_exists($this->caminhoLog)) {
            return [];
        }
        
        $linhas = file($this->caminhoLog, FILE_IGNORE_NEW_LINES | FILE_SKIP_EMPTY_LINES);
        $historico = [];
        
        foreach ($linhas as $linha) {
            $historico[] = json_decode($linha, true);
        }
        
        return $historico;
    }

    public function setCaminhoLog(string $caminho): void
    {
        $this->caminhoLog = $caminho;
    }
}

4. Enunciado da Atividade e Pistas Textuais

Sua Missão: Crie um arquivo MonitorProducaoTest.php na pasta tests/ e escreva cenários para provar a existência das falhas listadas abaixo. Não corrija a classe até que os testes apontem os erros.

Pista 1: O Colapso do Turno Inativo Unidade

O encarregado de turno reportou que o cálculo de OEE quebrou completamente com um Fatal Error. Isso ocorreu quando o sistema tentou processar a métrica de uma máquina reserva que esteve inativa e, portanto, teve exatamente 0 minutos de $tempoPlanejado.


Escreva um teste unitário que valide o comportamento do sistema quando o tempo planejado for 0 (deve retornar 0.0 em vez de estourar erro de divisão).

Pista 2: A Extrusora Fervente Unidade

Um operador de segurança notou uma falha perigosa no painel: a temperatura de uma extrusora cravou exatamente em 180°C, mas o sistema indicou "OPERACAO_NORMAL", quando o manual de segurança exige alerta "A partir de 180°C".


Monte um teste de limite (Boundary Test) passando exatamente o valor 180.0 para verificar o erro no operador relacional.

Pista 3: A Amnésia do Log de Sensores Integração

A equipe de dados está furiosa. Ao analisar o arquivo telemetria_maquinas.jsonl no final do dia, perceberam que ele sempre contém apenas o registro da última máquina auditada. Todos os milhares de registros anteriores foram apagados.


Crie um teste simulando a gravação de telemetria de duas máquinas diferentes (ex: INJ-01 e EXT-02) em sequência e afirme que lerHistoricoTotal() possui tamanho (count) igual a 2.

5. Entregas Esperadas

Para a conclusão desta atividade, você deverá apresentar:

  1. O arquivo MonitorProducaoTest.php configurado com os 3 testes falhando.
  2. O código original MonitorProducao.php corrigido.
  3. O print do terminal exibindo a execução do PHPUnit com 100% de sucesso.
